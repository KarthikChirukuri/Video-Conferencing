WebRTC

-> One of most common use of UDP is of WebRTC. which is used for video communication
-> WebRTC - web real time communication 
-> These are mainly built on UDP. These WebRTC works on bidirectional 
-> Here without WebRTC we send videos like from A to server and from server to B and vice versa. But using WebRTC it will establish an bidirectional connection between A and B. We use server based communication when reliability required. 

How does it work?
As said above to establish connection between the two machines like A and B in the above we will use four steps
Signalling, Connecting, Securing and Communicating 

1) Signalling - here we have one signalling server inside which have SDP. Here initially we send request to this signalling server. and this establish the connection between the machines. here for connecting between the two machines it uses IP addresses.
2) Connecting - Here we use ICE (Internet connectivity Establishment) protocol. This protocol takes the IP address and help in establishment of connection 
3) Securing - Here we use two protocols DLTS and SRTP. First here we secure the connection before sending data. Here we use the concept of encryption.
4) Communicating  - Here at last now we start communication. Here we uses protocols like RTP and SCTP. 
-> WebRTC as a technology not needed to be implemented from scratch it is already implemented. we can use it using the API's. 

MediaStream - Which is an API used to collect video and audio from our device. 
RTCPeerConnection and RTCDataChannel - using these we establish data communication between the client.
